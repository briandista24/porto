Tentang Saya

"Saya adalah seorang IT Profesional dengan pengalaman lebih dari 5 tahun, berawal dari keahlian mendalam (expert) di bidang IT Support & Hardware, hingga berkembang menjadi DevOps / Infrastructure Engineer. Saya memiliki spesialisasi dalam menjembatani infrastruktur legacy dengan teknologi kontainerisasi modern (Docker & Harbor), serta memastikan kelancaran operasional IT dari level end-user hingga server backend."

Pondasi di Infrastruktur & IT Support

Perjalanan karir saya di dunia IT dimulai pada Mei 2020 setelah lulus sekolah, berawal dari fundamental infrastruktur jaringan di Instansi AbiCom. Selama hampir dua tahun, saya terjun langsung ke lapangan untuk menangani instalasi jaringan (layanan WiFi) dan troubleshooting konektivitas. Memasuki tahun 2022, saya memperluas spesialisasi saya dengan bergabung di Iz Comp. Di sinilah saya mencapai tingkat keahlian bisa dibilang expert level dalam bidang IT Support, khususnya untuk perbaikan perangkat keras secara komprehensif mulai dari printer, komputer, hingga laptop. Pemahaman end-to-end dari sisi hardware dan jaringan ini membentuk insting problem-solving saya yang tajam.

Evolusi menjadi DevOps / Infrastructure Engineer

Pada Maret 2023, saya mengambil lompatan karir dengan bergabung di perusahaan manufaktur besar, CV. Karya Hidup Sentosa (Quick Traktor). Meskipun secara formal saya memegang jabatan sebagai IT Database Administrator, peran dan tanggung jawab operasional saya berada di ranah DevOps / Infrastructure Engineering.

Di posisi ini, saya menghadapi tantangan untuk menjaga stabilitas sistem legacy perusahaan yang menggunakan framework, environment, database yang dibilang cukup menantang. Karena sistem aplikasi yang end of life dan tidak mungkin dilakukan pembaruan (upgrade) dan apliasi harus tetap berjalan di era teknologi sekarang, saya berinovasi dengan mengimplementasikan teknologi kontainerisasi. Saya menjadi sangat ahli dalam mengelola ekosistem Docker, membuat dan menyesuaikan custom image melalui Dockerfile agar environment lawas tersebut tetap berjalan mulus, aman, dan terisolasi di perangkat modern ini. Seluruh hasil build image tersebut kemudian saya kelola dan distribusikan secara mandiri menggunakan Harbor Local Registry.

Melihat ke Depan

Dengan kondisi saya sekarang, saya memutuskan untuk mencari tantangan baru. Meskipun saya berhasil memaksimalkan potensi infrastruktur di lingkungan kerja saat ini, saya memiliki hasrat yang besar untuk terus mengeksplorasi teknologi baru, melakukan scale-up, dan tidak berhenti belajar. Saya mencari lingkungan kerja yang dinamis, di mana saya dapat menerapkan kombinasi keahlian IT Support dan manajemen Server/Deployment saya untuk membangun infrastruktur yang lebih modern dan scalable.
